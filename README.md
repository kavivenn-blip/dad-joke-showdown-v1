A single dad joke, written by a program, for make.fun's "Dad Joke Showdown" bounty: a father of three tells his car tires they look tired, and the tires answer back.

## Run it

```sh
python3 main.py
```

The program writes one dad joke (156 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic, no network, standard library only.
